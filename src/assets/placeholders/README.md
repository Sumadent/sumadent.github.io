# Asset Placeholders

This folder is designated for temporary asset placeholders, mockups, and sample images before the final photography assets are ready.

## Rules for Assets:
1. **Format**: Use `.webp` or `.png` for illustrations/renders, and `.svg` for icons.
2. **Naming**: Use lowercase kebab-case (e.g., `clinic-interior-placeholder.jpg`).
3. **Dimensions**: Mobile images should be optimized for a max-width of `750px`. Desktop hero assets should be `1920x1080px`.
